# 🐍 贪吃蛇大作战 · 幽灵战场

> 纯 H5 移动端贪吃蛇竞技 — 环形世界 × 异步幽灵 × 魂系交互

你在一个无边界的环形草原上与 10 条 AI 蛇搏斗。其他玩家的历史对局以半透明「幽灵蛇」在你身边实时重放——你能撞死它，它也能撞死你。仿佛随时有人在线上和你一起玩。

```
��            │  spatial (环面空间哈希)               │

│  game/     │  snake · world · ai · ghost ·        │
│            │  collision · food · powerup ·        │

│  render/   │  renderer (Canvas 2D) · hud (DOM) · │
│            │  minimap                             │

│  js/config.js  ← 全部数值集中管理，调参只改这里     │
└─────────────────────────────────────────────────┘
```

**技术选型**：

| 维度 | 选型 |
|------|------|
| 渲染 | 纯 Canvas 2D（无 WebGL、无引擎） |
| 模块 | ES Modules（零构建，原生 `import/export`） |
| 依赖 | **零 npm 依赖** |
| 循环 | 固定 60Hz 逻辑步长 + rAF accumulator + 120Hz ProMotion 兼容 |
| 音效 | WebAudio API 合成 |
| 持久化 | localStorage（回放 / 墓碑 / 蛇蜕 / 分数） |
| 回放编码 | 扁平数字数组 + 环形最短增量压缩 |

**设计原则**：
- 核心游戏逻辑（`js/game/`、`js/core/`、`js/config.js`）**环境无关**，不碰 DOM。Node 可直接 `import` 运行（`tools/gen_ghosts.js` 依赖此特性）
- 数据访问走 `Provider` 抽象（`js/game/provider.js`），本地/HTTP 双实现，接后端零改动
- 对象池化（`pool.js`）杜绝 GC 抖动

## 👻 异步幽灵系统

这是本游戏区别于传统贪吃蛇的核心设计：

1. **离线生成**：`tools/gen_ghosts.js` 用 Node headless 跑 AI 对局，产出真实回放数据
2. **运行时注入**：每局最多 6 条幽灵蛇并发重放，来自预置池 + 玩家自己历史对局
3. **双向交互**：
   - 你的头撞到幽灵身体 → 你死
   - 幽灵头撞到你的身体 → 幽灵「死」，化食物 + 立墓碑
4. **渐进在线感**：幽灵池循环使用，玩家自己的对局会进入下一局的幽灵池——「遇到昨天的自己」
